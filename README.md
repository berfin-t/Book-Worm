## 📖 About the Project

**Bookworm** is a modern **full-stack e-commerce application** built with **ASP.NET Core Web API** and **React.js (TypeScript)**.  
The project is designed with real-world e-commerce scenarios in mind, focusing on **scalability**, **security**, and **maintainability**.

The frontend and backend are developed as fully decoupled applications.

---

## 🚀 Tech Stack

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- ASP.NET Identity & JWT Authentication

### Frontend
- React.js
- TypeScript
- Material UI (MUI)
- Redux Toolkit
- React Router
- Axios

---

## ✨ Features

### 👤 Authentication & Authorization
- JWT-based authentication
- User registration and login
- Secure token management

### 🛍️ Product Management
- Product listing
- Product detail pages

### 🛒 Cart & Orders
- Add / remove products from cart
- Cart synchronization
- Order creation
- Order history
